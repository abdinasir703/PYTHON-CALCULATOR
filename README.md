## PYTHON-CALCULATOR
-A simple command-line calculator made with python. your enter an operator and it print result

## FEATURES
-Addition,subtraction,multiplication and division
-Works with whole numbers and decimal
-shows a message if the operator is not valid

## REQUIREMENTS
-python any version that works on your machine
-code editor in my case i use pycharm

## EXAMPLE
-enter an operator(+*-/):+
-enter the first number :5 
-enter the second number 10
-result=15.0

-getting user input with 'input()'
-converting text to numbers with 'float()'
-making decisions with 'if','else' and 'elif'
